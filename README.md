📘 MyStudy – Personal Study Tracker Web App

MyStudy is a full-stack web application designed to help students track their daily study activities and analyze subject-wise progress.
This project focuses on real-life usability, not just academic requirements.

🚀 Project Overview

As a student, consistency and self-analysis are key to better learning.
MyStudy allows users to log their daily study hours, view detailed study history, and analyze performance using charts — all in one simple dashboard.

This project strengthened my understanding of backend development, database integration, and data analysis.

✨ Key Features

🔐 User Authentication (Register & Login)

📝 Daily Study Log (Date, Subject, Study Hours)

📊 Subject-wise Study Analytics

📈 Automatic Chart Generation using Matplotlib

🗂 Study History with Delete Option

🧼 Clean and Simple Dashboard UI

🔁 Real-time data updates

🛠️ Tech Stack

Backend: Python, Flask

Frontend: HTML, CSS

Database: MySQL

Data Analysis: Pandas

Visualization: Matplotlib

Tools: Git, GitHub
